OpenTrack (Proton / Wine games, X-Plane, FlightGear…)

Status—
  1. OpenTrack : Input = “UDP over network”, port 4242. Begin with Start.
  2. Output : “Wine” (Proton / Wine games: DCS, MSFS, IL-2, Elite, Star Citizen… protocol Both, choose your Proton version and AppID), “X-Plane”, “FlightGear”, or “libevdev joystick”.
  3. OpenTrack curves and filters still apply; set smoothing below to 0 if using those. Recenter here or use OpenTrack’s Center key.

Virtual joystick (native Linux games, without OpenTrack)

Status—
  1. Euro Truck Simulator 2 / American Truck Simulator (native): bind camera axes in controls_linux.sii (guide in docs/SIMS.md).
  2. War Thunder (native), FlightGear, X-Plane: bind horizontal/vertical camera movement to joystick RX / RY axes.
  3. Access to /dev/uinput is required (same permission as the mouse).

Calibration and tilt

Settings

Limitations

  • The watch streams only itsaccelerometer : 3 samples every 120 ms (24.9 Hz), 12-bit, ±8 g. No live gyroscope.
  • This measurestilt (gravity direction), rather than rotation around vertical. Rendering at 120 Hz smooths the 25 Hz samples.
  • Latency: about 80 ms batching inside the watch, plus BLE bursts (130 ms median, 240 ms p95).
  • Lowering your arm (large tilt) pauses control. Tapping freezes the cursor for 0.35 seconds and cancels the small movement caused by the tap.

Discoveries

Findings from reverse engineering; details in REVERSE_ENGINEERING.md.
  • User acceleration [38:44] (gravity removed, ~1000 = 1 g): noise around 0.02 g at rest, suitable for experimental glide mode with a reset at each stop.
  • MTU L2CAP : at 672 bytes (Linux default), AirPods 3 hide their sensors; at 2582 (as used by iOS) they expose devmotion6, accel, gyro, cma, kadabra.
  • Apple RemoteHID (RTBuddy channel 0x800): each sensor is a virtual HID device. The u32 subpacket header contains deviceID (7 bits), length (10 bits), and type (3 bits).
  • HostConnect 00 gg 00 00 | 00 02 00 00 → AirPods publish sensors (DeviceConnect + plist + HID descriptor).
  • SetReport feature 1 = Report Interval (µs) on devmotion6 → motion stream up to ~200 Hz.
  • Shared 58-byte AirPods 3 / Pro block: quaternion Q15 [20:26], gyro [26:32] (~0.122 °/s per unit), acceleration [38:44], gravity [44:50] (~1000 = 1 g).
  • AirPods Pro 2: protocol SensorDataWX (protobuf, 0x100000) — ACTIVITY(14) then DEVMOTION6(16).
